# Xentropy plugins

Official Xentropy integrations for AI agent harnesses: Claude (Claude Code, claude.ai, Cowork), OpenAI (Codex, ChatGPT), pi, Hermes Agent and OpenClaw.

Every integration connects to the Xentropy remote MCP server at `https://api.xentropy.ai/mcp`. Sign in with OAuth, or use a scoped API key where OAuth is unavailable. Skills under `skills/` are generated from the Xentropy skills corpus; do not edit them by hand.

Status: in development. See https://docs.xentropy.ai for connection guides.
